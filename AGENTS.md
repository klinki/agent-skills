## Working defaults

- Use concise, outcome-first communication.
- When coding, prioritize simplicity and readability.
- Prefer the simplest solution that meets the goal.
- Avoid unnecessary helpers unless they make the code simpler or clearer.
- Preserve unrelated user changes and protect credentials and secrets.
- Make requested edits and run proportionate verification checks, reporting what was checked.
- Follow Conventional Commits when creating commits.
- Never push changes.
- Never perform destructive operations unless explicitly authorized.
- Apply nearer, project-specific `AGENTS.md` instructions when they conflict with these global defaults.
